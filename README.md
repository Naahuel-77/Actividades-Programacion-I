# Actividades de Programación I

Desafíos de programación en Python, organizados por bloque. Cada carpeta `Bloque N/N.M` contiene los desafíos de ese bloque.

## Cómo ejecutar un desafío

Abrí una terminal dentro de la carpeta del desafío y ejecutá el archivo. Por ejemplo:

```
cd "Bloque 5/5.17"
python Desafio87_5.17.py
```

Algunos desafíos leen o escriben archivos de datos (`libros.txt`, `prestamos.txt`, `inventario.csv`). Esos archivos están en `Bloque 5/5.17`, junto a los programas que los usan (desafíos 86 al 90).

## Notas

- En los bloques 1 y 2 la numeración de los archivos reinicia en cada carpeta, por eso se indica el bloque en el índice.
- El desafío 36 está dividido en dos archivos (`formato` y `principal`).
- Los desafíos 47, 48, 49, 50, 51, 54, 57 y 59 están resueltos en un mismo archivo: `Bloque 4/4.12/Desafio47_48_49_50_51_54_57_59.py`.
